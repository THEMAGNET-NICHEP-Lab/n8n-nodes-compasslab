# Workflow templates

Ready-to-import n8n workflows that use the CompassLab nodes. Import one in n8n with **Workflows > Import from
file**, then follow the yellow note in the workflow (5 minutes of setup).

| Template | Node | What it does |
|---|---|---|
| [clean-signup-list.json](clean-signup-list.json) | CompassLab (Email) | Every day, validates the new email addresses in a Google Sheet and writes the verdict and a typo fix next to each one |
| [pdf-invoices-to-text.json](pdf-invoices-to-text.json) | CompassLab (PDF) | When an email with a PDF arrives in Gmail, extracts the PDF text and logs it with sender, subject and pages in a Google Sheet |
| [website-to-contacts.json](website-to-contacts.json) | CompassLab (Company Contact) | Every day, finds the business email, phone, LinkedIn page, legal name and VAT ID of new company websites in a Google Sheet |

The `*.test.json` files are the same workflows with the Google steps replaced by sample data; they are used to test
the templates against the live APIs. The files are generated by `scripts/n8n_templates.py` in the CompassLab source
repository.
